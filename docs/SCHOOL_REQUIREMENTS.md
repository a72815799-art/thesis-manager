# 학교 공식 안내 확인 기록 (단국대학교 행정법무대학원)

확인일: 2026-11-22. 확인 방법: 공식 사이트 두 페이지를 내려받아 본문 텍스트를 읽음.
이 문서는 **공식 안내를 읽은 기록**이며, 이 앱이 학교 양식과 호환된다는 뜻이 아닙니다(호환성은 미검증).
학사 요건은 바뀔 수 있으므로 실제 진행 전에 반드시 대학원 행정실과 최신 공지를 확인하세요.

페이지 제목: “학위 취득(논문)”. 본문은 “학위논문 제출절차 개관도” 하나입니다.

| 1. 연구계획서(proposal) | “과정이수 중 적절한 시기에(발표하고) 지도교수에게 제출” / 함께 표기: 소요학기 등록, 요구학점취득, 각종자격시험 합격(외국어, 종합학력자격시험) |
| 2. 학위논문작성 | (설명 없음) |

| 7. 학위논문 제출 및 논문등록 | 학생 → 중앙도서관 |
| 8. 학위수위자 확정 | 대학원 (표기는 페이지 원문 그대로) |

**이 페이지에 없는 내용(확인 필요)**: 연구계획서의 양식·분량·제출 기한, 외국어·종합시험의 구체적 기준, 심사 일정, 논문 작성 형식, 연구윤리(IRB)·표절 검사 기준.

## 3. 앱과의 관계

| 항목 | 상태 |
|---|---|
| 공식 안내 확인 | 위 범위까지 확인 |
| 앱의 연구계획서 DOCX가 학교 양식과 맞는지 | **미검증**. 앱은 자체 10개 항목 구성으로 문서를 만듭니다. 학교가 정한 연구계획서 양식은 확인하지 못했습니다. |
| “학위논문 작성틀”·“논문지도교수 승인 요청서” 반영 | 미반영. 파일을 확인한 뒤 후속 단계(원고·심사 영역)에서 검토 대상 |
| HWP 호환 | 보장하지 않음 |

절차 개관도의 단계(계획서 → 예비발표 → 심사신청 → 심사 → 제출)는 후속 8번 영역(심사·제출 체크리스트)의 기준 자료로 쓸 수 있습니다.
학교 양식은 연구 데이터와 분리해(`ProposalSnapshot` → 내보내기 모듈) 양식별로 버전 관리하도록 설계했습니다.
